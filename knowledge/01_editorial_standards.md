# Editorial standards (fictional demo)

## Fact checking
Editors verify numerical claims against primary sources or original datasets whenever possible. The source link or document reference must be recorded before an article is published.

## Corrections
If a published article contains a factual error, the editor verifies the correction, updates the article, and adds a visible correction note. Significant corrections should be reviewed by the section lead.

## Anonymous sources
Anonymous sources require approval from an editor. The reason for anonymity should be documented internally. Do not disclose the identity of a confidential source in a public article.
